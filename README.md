# Лаборатория чистоты — Railway

Готовый фронтенд. Статика обслуживается Nginx, порт берётся из PORT (по умолчанию 8080). База данных для прототипа не нужна.

## Через терминал (Node.js и npm должны быть установлены)

Распакуйте архив, перейдите в папку cleanlab-railway с Dockerfile и выполните:

```bash
npm install -g @railway/cli
railway login
railway init
railway up
railway domain
```

При init создайте новый проект. При up выберите или создайте сервис, если CLI предложит. Если проект уже создан, вместо init используйте railway link и выберите проект/окружение/сервис. Если CLI просит сервис, создайте Empty Service в Railway и выполните railway link ещё раз.

После успешного деплоя railway domain создаёт публичный адрес. Альтернатива: сервис → Settings → Networking → Public Networking → Generate Domain. Если запрашивается порт, используйте значение PORT (по умолчанию 8080).

## Через GitHub

Загрузите содержимое этой папки в свой репозиторий так, чтобы Dockerfile, railway.json и dist находились в корне. В Railway создайте проект через Deploy from GitHub repo, выберите репозиторий. Dockerfile будет обнаружен автоматически. После деплоя создайте домен в настройках сервиса. Дополнительные Build Command и Start Command не требуются.

## Локальная проверка с Docker

```bash
docker build -t cleanlab .
docker run --rm -p 8080:8080 cleanlab
```

Откройте http://localhost:8080. Проверка здоровья: http://localhost:8080/health.

## Границы прототипа

Это демоверсия без серверной авторизации и совместной работы. Данные сохраняются в localStorage браузера; на новом домене начнётся отдельное хранилище. Данные из версии ChatGPT Sites автоматически не переносятся. После создания публичного домена интерфейс доступен всем, у кого есть ссылка. Не используйте его для реальных корпоративных данных до подключения авторизации и backend.
